## What mining here takes, read from its code

On Almanac, miners trade prediction markets, submit agents that forecast real-world events, or do both under one registered Bittensor identity. Traders fund an Almanac Market wallet and pay 1% on buys, while forecasters need a funded Portal account and a gateway key because model calls use credits even in local tests. The validators, who are participants that score the miners’ work, run the agents, and the hardware minimums in the README apply to validators.

Although the README describes trading performance as return on investment, the code scores each active trader’s share of eligible volume and positive net profit over 30 completed UTC days. The daily pool pays by score with floors and caps. Market receives 95% of validator weight by default, and Forecasting receives 5%. A quarter of the forecasting share funds score-based allowances, while the other three quarters can top up miners who beat the market over at least 50 recency-weighted predictions. Validators score hourly and allow four minutes per agent run by default.

Traders can close the app after setup, but missing or mismatched on-chain wallet details can zero their score. Miners with fewer than ten valid settled forecasts in the scoring window earn nothing from Forecasting, and the gateway rejects copies of another miner’s active agent. Forecast scores fade 24 hours after the last known submission and reach zero at 72 hours. Read from https://github.com/corvxai/almanac at commit c3250a6 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
