# Hone, Bittensor subnet 5: what happened to the entries that paid to get in

This page is written for an operator, or for the agent working for one, who is about to pay the entry fee of Hone. Everything on it was read from the Bittensor chain up to November 23, 2026 at 12:05 UTC, nothing is predicted, and every dollar amount uses the price of the day it was paid.

In Bittensor's own words this page is about mining on subnet 5. The fee is the registration cost that a new miner burns, an entry is one hotkey registered as a miner, what came back is the miner's emissions valued in dollars, an entry that is removed has been deregistered, and the days it takes for the fee to come back are the time to break even.

The contest describes itself as follows, and these are its own words copied from the chain, not a judgment of this site: "Hone (SN5) is an RLVR subnet: reinforcement learning from verifiable rewards. Miners are paid to solve real software-engineering tasks- repository patches submitted as git diffs and terminal tasks submitted as scripts with full trajectories. Validators lease tasks from a problem server and grade every response deterministically in isolated Docker verifiers, so rewards reflect verified outcomes only. Each scored solution becomes high-quality, verifiable RL training data for post-training code ..."

## If you are about to pay the entry fee

The fee is $59.48 right now, and over the last 30 days it has been as low as $32.87 and as high as $239, because it moves with demand. The fee is burned when the entry is made and is never returned, whether or not the entry is ever paid.

Of the 359 entries made 2 to 14 days ago, 46 are still in the contest and 85 already have their fee back. A typical one that is still in is paid $27.58 a day today, about the same as a week ago, when it was $24.96, but most entries here do not last: only 46 of those 359 are still in, and an entry that is removed keeps what it was paid and loses its fee, so the days it would take to earn the fee back at that pay mean little.

## What mining here takes, read from its code

A Hone miner solves a coding task with a Git patch or Bash script, then uploads it with a record of the model’s work and signs the response. Validators, the participants who score the miners’ work, need a public TCP port to reach the miner. The demo uses a funded, registered hotkey, the key a miner works with, and a Bedrock API key for paid model calls. It needs temporary disk space equal to the compressed task plus twice its expanded size, and no CPU, GPU memory or uptime minimum is stated.

Every hidden check must pass to earn one point, and speed adds no bonus. Validators pool up to 50 results per validator per miner over four days, and although the README describes an average, the code divides by at least 30 observations. Positive scores share rewards by rank, so each miner gets 99.5% of the weight above it, with ties favoring the lower UID.

The policy cites 36 hours of registration protection and schedules rounds 38 blocks apart. A lease needs ten minutes left at dispatch, but the demo allows at most 280 seconds by default, including 20 for uploads. The demo’s example selects the test network, while subnet 5 runs on Finney. Once observed, an offline miner can receive zeros on completed rounds. Read from https://github.com/hone-subnet-org/hone-subnet at commit db5b106 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
