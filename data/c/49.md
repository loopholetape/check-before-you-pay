## What mining here takes, read from its code

A miner trains a simulated robot to navigate, then signs and uploads the policy for a Nepher Robotics tournament on Bittensor subnet 49. Training calls for an NVIDIA GPU with at least 24 GB of graphics memory, but a CPU suffices for uploads. The repository’s miner guide and configuration both specify Isaac Sim 6.1 and Isaac Lab 3.0.0. To enter, a miner needs an API key from a Nepher account and a hotkey, the key a miner works with, that is registered on subnet 49.

Uploads open at contest start and close at contest end. Validators, the participants who score the miners’ work, evaluate only the latest submission per hotkey and test the policy on hidden scenes. The README says the winner takes all, but the code gives each eligible preliminary leader of a tournament outside its reward period 1% of the total weight. The code divides the remainder among eligible finishers on the approved podium in proportion to the shares supplied by the tournament API, and if none qualify, it burns the remainder.

A finisher’s hotkey must be registered when validators calculate its share. Each tournament sets its schedule, and the repository’s miner guide specifies no registration protection period, fixed round length, miner disk minimum, uptime requirement or public port. Read from https://github.com/nepher-ai/nepher-subnet at commit c4c3f11 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
