This page is written for an operator, or for the agent working for one, who is about to pay the entry fee of CliqueAI. Everything on it was read from the Bittensor chain up to November 23, 2026 at 12:05 UTC, nothing is predicted, and every dollar amount uses the price of the day it was paid.

In Bittensor's own words this page is about mining on subnet 83. The fee is the registration cost that a new miner burns, an entry is one hotkey registered as a miner, what came back is the miner's emissions valued in dollars, an entry that is removed has been deregistered, and the days it takes for the fee to come back are the time to break even.

The contest describes itself as follows, and these are its own words copied from the chain, not a judgment of this site: "CliqueAI - AI-Powered Maximum Clique Solver Network"

## What mining here takes, read from its code

On CliqueAI, Bittensor subnet 83, a miner receives a graph and returns the largest group it can find in which every pair of vertices is connected.

A CPU-only miner needs four 2.5 GHz x86_64 cores, 16 GB RAM, 4 GB swap and 10 GB free storage, while an optional GPU has an 8 GB memory minimum and a 24 GB recommendation. The miner serves a public port using a Bittensor wallet and a hotkey, which is the key a miner works with. The miner setup and mechanism guide reviewed here list no required third-party miner account or API key, extra fee or registration protection period.

A group scores zero if another vertex could join it. Validators, the participants who score the miners' work, compare valid groups by size and by how often miners returned the same vertices, and size counts more on harder graphs. They average scores over time and aim to give the top half of ranked entries 80% of their weight.

Validators target 60-second rounds and skip entries updated within 361 blocks by default. Although the README links selection to past scores, eligible miners have equal chances on each graph. Deadlines are 6, 7.5, 10, 15 or 30 seconds. The code adds a fourth graph size beyond the guide’s three, and these 890–900-vertex graphs exclude the six-second deadline. Read from https://github.com/toptensor/CliqueAI at commit 0d3488a on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
