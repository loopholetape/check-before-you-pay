This page is written for an operator, or for the agent working for one, who is about to pay the entry fee of Gittensor. Everything on it was read from the Bittensor chain up to November 26, 2026 at 12:05 UTC, nothing is predicted, and every dollar amount uses the price of the day it was paid.

In Bittensor's own words this page is about mining on subnet 74. The fee is the registration cost that a new miner burns, an entry is one hotkey registered as a miner, what came back is the miner's emissions valued in dollars, an entry that is removed has been deregistered, and the days it takes for the fee to come back are the time to break even.

## What mining here takes, read from its code

A Gittensor miner submits changes to approved open-source projects, reports issues that someone else fixes, or supplies a GPU server. For GitHub work, the project lists two CPU cores and 4 GB of RAM, and no server needs to stay online. When a validator, a participant that scores the miners' work, first accepts your fine-grained, read-only GitHub token, it binds that account to your registered wallet hotkey, the key a miner works with. GPU mining requires a supported card, 100 GB of free storage and a publicly reachable server that passes periodic checks.

When projects are funded, validators weigh code changes, and each project normally requires three qualifying merged pull requests and an 80% merge rate among merged and closed requests. Contributors share each pool in proportion to score, while an open request normally reserves 20% of its potential score in points. Scoring runs about every two hours and looks back 30 days by default, and the 12-hour grace period starts at merge.

The project describes earnings for this work, but at the reviewed commit the project list is empty and the GPU share is zero, so all miner emissions go to UID 0 for recycling. If you want to change GitHub accounts, the validator tells you to deregister and re-register. Read from https://github.com/entrius/gittensor/tree/main at commit 884ce17 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
