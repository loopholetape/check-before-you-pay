## What mining here takes, read from its code

A miner on Score builds a model that answers questions about video or images, such as when a football pass happened or what grade a trading card deserves. Both tracks require a Bittensor hotkey, the key a miner works with, that is registered on subnet 44, but the sample configuration points to test subnet 423.

Public miners publish on Hugging Face using separate write and read tokens, and they deploy through a funded Chutes developer account with an API key. Deployment accepts a fee whose amount is unstated, and the example requests one GPU with at least 16 GB of video memory. Private miners run a Docker container on a public port, normally 8000, and must give Score read access to their GitHub package to pass spot checks.

Validators are participants who score the miners’ work. They compare answers with reference data and ordinarily need 30 challenges to rank a miner. A public winner gets its task’s whole share, while the top three eligible private miners normally receive 80%, 15% and 5% of their task’s share. Tasks default to evaluation every 300 blocks, public scores look back three days by default, and private requests default to 30 seconds. The public speed test targets 100 ms per frame on two virtual CPUs, with 10 ms of tolerance at the 95th percentile.

After re-registration, a public miner can still meet the recovery deadline in the block of the seventh indexed evaluation for its task after its last recorded result. The miner guides give no immunity period after initial registration. Read from https://github.com/score-technologies/turbovision at commit 92079a4 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
