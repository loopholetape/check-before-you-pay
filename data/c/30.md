## What mining here takes, read from its code

Miners on Endure forecast each listed Alpha token’s worst peak-to-trough price drop, volatility, time-weighted average price and time-weighted average TAO reserve in its pool over 5 and 30 days. Each day they send a hash to validators, who are participants that score the miners' work, between 11:00 and 19:30 UTC, then reveal the matching forecasts and secret nonce from 20:30 to midnight.

The reference miner uses a CPU, persistent storage, a public IP and a port such as 8092, and a chain data endpoint. It needs a funded Bittensor mainnet wallet and a hotkey, the key a miner works with, registered on subnet 30. The deployment guide gives a public endpoint and lists no paid service for it. The protocol requires no extra miner stake, and the mainnet guide tells operators to check chain-controlled fees when registering. The README gives no hardware sizing figures, and the mining guide specifies no minimum runtime for scoring.

Validators compare predictions with market outcomes and give small errors full credit, then reduce the score linearly to zero. An error that understates risk reaches zero at one-third the error allowed in the cautious direction. Accuracy has a five-round half-life for each subnet, output and horizon, and validators cube the combined score to calculate reward weights. A positive five-day result can make a miner eligible for rewards around day six, and thirty-day results begin contributing around day 31.

From a miner’s first accepted round onward, skipped predictions score zero when they resolve. Identical forecasts share the weight the best member of their pool would earn alone. A 98% owner-set burn leaves miners about 2% of each validator’s vote to split, while an invalid or missing rate leaves them nothing, as does having no positive miner score. The code at this commit requires protocol key 2044. Read from https://github.com/Endure-Network/endure-subnet at commit 81644bd on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
