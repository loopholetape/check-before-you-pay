## What mining here takes, read from its code

A ChronoLLM miner trains a language model for each year from 2013 through 2024, using only information available by that year’s cutoff. Miners upload the models to Hugging Face and submit a public list linking each year to an exact model commit. They submit it with a registered subnet 38 hotkey, which is the key a miner works with.

Training requires a GPU, and automatic upload requires a Hugging Face write token. The guide specifies no minimum GPU memory, disk space, public port, always-on miner server, extra fee or post-registration protection period. The optional CPU self-test allows 12 calls per hotkey daily.

Validators, who are participants who score the miners’ work, test knowledge from before and after each cutoff and then compare qualifying models’ completions head to head. The README describes ranking by wins alone, but the code defaults to 30% for the cutoff test and 70% for the duel win rate. Up to ten miners share the miner allocation by rank, and when ten earn rewards, the first three receive about 52%, 23% and 12% of that allocation.

Each weekly submission is due Monday at 12:00 UTC, and private models must be public before 13:00 UTC that day. Any year you miss scores zero. Read from https://github.com/chronollm/sn38 at commit 1c093d4 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
