# True Performance Network, Bittensor subnet 65: what happened to the entries that paid to get in

This page is written for an operator, or for the agent working for one, who is about to pay the entry fee of True Performance Network. Everything on it was read from the Bittensor chain up to November 23, 2026 at 12:05 UTC, nothing is predicted, and every dollar amount uses the price of the day it was paid.

In Bittensor's own words this page is about mining on subnet 65. The fee is the registration cost that a new miner burns, an entry is one hotkey registered as a miner, what came back is the miner's emissions valued in dollars, an entry that is removed has been deregistered, and the days it takes for the fee to come back are the time to break even.

The contest describes itself as follows, and these are its own words copied from the chain, not a judgment of this site: "Distributed AI model compression & optimization engine"

## If you are about to pay the entry fee

The fee is $38.16 right now, and over the last 30 days it has been as low as $36.13 and as high as $51.45, because it moves with demand. The fee is burned when the entry is made and is never returned, whether or not the entry is ever paid.

Only 2 entries were made between 2 and 14 days ago, which is too few to say what a new entry gets right now.

## The contest today

All 256 slots are taken, so every new entry removes the lowest-paid entry that is past its protected period, which lasts about 17 hours after an entry is made. $579 a day is paid to entrants today, 1 wallet receives $5 a day or more, and the largest wallet takes 100% of the total.

## What mining here takes, read from its code

A miner on TAO Performance Network, subnet 65, quantizes the competition’s base language model into a GGUF file, uploads it to a private Hugging Face repository and commits the file version and benchmark run IDs on chain. This takes a registered Bittensor hotkey, the key a miner works with, as well as Hugging Face write access and a funded benchmark account with an API key and a stored token that can read the model. The service measures the GPU memory needed to load the model and quotes the required tests, and the guide’s example costs $11.56. The miner guide gives no minimum local hardware, uptime or public port requirements.

Models must pass every benchmark minimum and have a verified GPU memory measurement. The default contest rewards the lowest GPU memory use, while a memory-capped contest ranks models within the cap by their weakest benchmark result, adjusted for fidelity when required. The validator, a participant that scores the miners’ work, scores every qualifying entry, and payout to the configured places begins at the scoring-end block. The default is five places, and the local example pays 60% of its pool to first place and 40% to second. The leader validator supplies the live competition settings, so the live split and round length could not be verified from the repository.

The miner guide specifies no protection period after registration. Once commitments close, miners have a reveal window of 150 blocks by default to publish the repository before scoring. A run ID can arrive before a test finishes, but an unfinished test or a test of the wrong repository, revision or file earns zero for that benchmark. If the repository is still private at scoring, it loses every result. Read from https://github.com/taofu-labs/true-performance-network at commit 9f80c19 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
