In Bittensor's own words this page is about mining on subnet 123. The fee is the registration cost that a new miner burns, an entry is one hotkey registered as a miner, what came back is the miner's emissions valued in dollars, an entry that is removed has been deregistered, and the days it takes for the fee to come back are the time to break even.

## What mining here takes, read from its code

A MANTIS miner forecasts financial markets and refreshes an encrypted file in Cloudflare R2 about once a minute, using an address registered on-chain and a filename that matches the miner’s hotkey, the key the miner works with. The miner guide calls for continuous breakout submissions.

The minimum-compute file lists an RTX 4090 and gives no memory, disk or public-port minimum. FLOW miners post collateral and pay gas through an EVM account, while LOOP miners pay for model calls with a prepaid SayGM key.

Validators, who are participants that score the miners’ work, measure how much each signal helps predict later outcomes and combine scores by challenge weight, reserving 52% for burning. New miners receive a weight floor for about 12 days from their first recorded submission. In FLOW, weekly settlement distributes losses to net winners, and seven days after a miner’s first resolved trade, a positive score can earn a proportional share of 98% of FLOW’s allocation. LOOP takes 5% and rewards audited improvements on the best trading score.

The cited validator code gives no duration for the chain’s registration immunity period. The guide’s four-week test no longer controls payment, and FLOW represents 4.75% of configured challenge weight despite the guide’s 25% figure. LOOP’s daily cutoff is midnight UTC, and the balance on the prepaid SayGM key must be positive and at most $100, despite the README’s $25 figure. Read from https://github.com/Barbariandev/MANTIS at commit 388efd9 on 2026-11-23.

## What this page cannot see

These figures count the entry fee and nothing else. Some contests charge again for every upload or task, and running an entry has its own costs in machines, model calls and time, and none of that is in here. What the contest asks of an entry is set out in the section above, which AI agents read from its code on 2026-11-23, and since code changes, the contest's own code and rules remain the authority. An entry that came and went within four hours can be missed, and a wallet is only an address, so one person can stand behind several.
